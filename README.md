# Introducción a la bioinformática con un enfoque al análisis del microbioma

Este curso forma parte de la colaboración entre el **Laboratorio Nacional en  Salud de la Facultad de Estudios Superiores Iztacala, UNAM** con la **Universidad Juárez Autónoma de Tabasco**. Es un curso intensivo de bioinformática orientado a la adquisición de herramientas bioinformáticas - linux y R - para el análisis del microbioma.

## **Objetivo del curso**

Adquirir habilidades en el uso de comandos de Linux y R para implementar un flujo de trabajo bioinformático orientado al análisis de datos de microbioma. 

El flujo incluirá el procesamiento y control de calidad de secuencias de amplicones mediante QIIME2, así como el análisis de diversidad microbiana, composición taxonómica y visualización de resultados mediante R y el paquete microeco, con el propósito de interpretar de manera reproducible los cambios en la estructura y composición de las comunidades microbianas.

# Introducción a la bioinformática con un enfoque al análisis del microbioma

Este curso forma parte de la colaboración entre el [**Laboratorio Nacional en  Salud de la Facultad de Estudios Superiores Iztacala, UNAM**](https://labnalsalud-fes.iztacala.unam.mx/) con la **Universidad Juárez Autónoma de Tabasco**. Es un curso teórico-práctico orientado a la adquisición de herramientas bioinformáticas - linux y R - para el análisis del microbioma.

## Objetivo del curso

Adquirir habilidades en el uso de comandos de Linux y R para implementar flujos de trabajos bioinformáticos orientado al análisis de datos de microbioma. 

## Estructura del repositorio

Este repositorio proporciona a los participantes los materiales de consulta, comandos, scripts y recursos utilizados para el curso. 

Los materiales del curso se encuentran organizados de la siguiente manera:

**[00_Técnicas de secuenciación masiva y Aplicaciones de la secuenciación masiva](https://github.com/Martinez-Gregorio-Hector/Curso_UJAT/tree/main/Presentaci%C3%B3nDiapositivas) - 30 de noviembre 2026**

Conocerás las técnicas moleculares que se usan en la preparación de bibliotecas, las diferentes tecnologías que se usan para la secuenciación masiva y sus principales aplicaciones

**[01_Introducción_a_linux.md](01_Introducción_a_linux.md) - 2 de diciembre 2026**

Desarrollarás habilidades básicas para utilizar la terminal de Linux, gestionar archivos y directorios y ejecutar comandos fundamentales


**[02_Introducción_a_R.md](02_Introducción_a_R.md) - 4 de diciembre 2026**

Aprenderás los fundamentos del lenguaje de programación R, desde el manejo de datos y la utilización de funciones y paquetes hasta la generación de análisis estadísticos y visualizaciones para la interpretación de datos biológicos.

**[03_pipeline_QIIME2.md](03_pipeline_QIIME2.md) - 7 de diciembre 2026**

Aprenderás a utilizar QIIME 2 para desarrollar flujos de trabajo bioinformáticos (pipelines) orientados al análisis del microbioma, desde el procesamiento y control de calidad de secuencias hasta la identificación taxonómica, el análisis de diversidad microbiana y la interpretación de resultados.


**[04_pipeline_microeco.md](04_pipeline_microeco.md) - 9 de diciembre 2026**

Aprenderás a utilizar el paquete microeco en R para el análisis ecológico del microbioma, explorando herramientas para evaluar la diversidad microbiana, identificar microorganismos diferencialmente abundantes, analizar patrones de composición y estructura de comunidades microbianas, e interpretar sus relaciones con variables ambientales o clínicas.

## Que necesitamos para este curso

1. El curso tiene un enfoque teórico-práctico, por lo que es indispensable contar con una computadora. Se recomienda utilizar un equipo con sistema operativo **macOS o GNU/Linux**.

    Si cuentas con una computadora con **Windows** tienes que instalar [MobaXterm](https://mobaxterm.mobatek.net/download.html), una aplicación que proporciona un entorno de terminal compatible con herramientas de Linux. Además, integra un servidor gráfico X11, un cliente SSH para establecer conexiones remotas seguras y diversas herramientas de red que facilitan el trabajo en entornos de cómputo y servidores.

2. Editor de texto. Es necesario contar con un editor de texto para crear, modificar y guardar archivos de código y scripts durante las sesiones prácticas del curso.

      Puedes utilizar cualquiera de las siguientes opciones:
   
   [Visual Studio Code](https://code.visualstudio.com/)

   [Sublime Text](https://www.sublimetext.com/3)

   [Atom](https://atom-editor.cc/)

    También puedes utilizar cualquier otro editor de texto de tu preferencia, siempre que permita trabajar con archivos de código.

    Importante: **No utilizar Microsoft Word ni otros procesadores de texto, ya que pueden modificar el formato del código y generar errores al ejecutarlo**.

3. Instalación de R y RStudio. Para realizar los análisis bioinformáticos y estadísticos durante el curso, es necesario instalar [R](https://www.r-project.org/) y [RStudio](https://posit.co/products/open-source/rstudio), que utilizaremos como entorno de programación y análisis de datos.
